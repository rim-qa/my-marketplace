# my-marketplace

Claude 플러그인 마켓플레이스입니다.

## 포함된 플러그인

| 플러그인 | 설명 |
| --- | --- |
| `weekly-sales-report` | 구글 시트 `_판매관리`의 판매내역으로 지난주(월~일) 매출 리포트를 만들어 슬랙에 발송합니다. 채널에는 한 줄 제목만 올리고 리포트 본문은 스레드에 답니다. |

## 설치 방법

### Claude Code (터미널)

```bash
claude plugin marketplace add rim-qa/my-marketplace
claude plugin install weekly-sales-report@my-marketplace
```

설치 확인:

```bash
claude plugin list
```

### Claude 앱

1. 왼쪽 사이드바에서 **Customize** → **Plugins** 탭으로 이동합니다.
2. **Add** → **Add marketplace** → **Add from a repository**를 선택합니다.
3. `rim-qa/my-marketplace`를 입력합니다.
4. **Discover**에서 `weekly-sales-report`를 선택하고 **Add**를 누릅니다.

## 사용 전 준비

`weekly-sales-report`는 아래 두 서비스를 사용하므로, 설치한 사람이 각자 Claude에 연결해 두어야 합니다.

- Google Sheets (판매내역이 있는 시트)
- Slack (리포트를 보낼 채널)

## 스킬 내용 (weekly-sales-report)

> 아래는 [`SKILL.md`](plugins/weekly-sales-report/skills/weekly-sales-report/SKILL.md)의 내용입니다. 스킬을 수정하면 이 부분도 함께 갱신해 주세요.

- **name**: `weekly-sales-report`
- **description**: 구글 시트 '_판매관리'의 판매내역으로 지난주 주간 매출 리포트를 만들어 슬랙 채널에 첫 줄 메시지와 스레드로 발송한다. 주간 매출 리포트 요청 시 사용.

구글 시트의 판매내역으로 지난주(월~일) 매출 리포트를 만들어 슬랙에 보낸다. 슬랙 채널에는 한 줄 제목만 올리고, 리포트 본문은 그 메시지의 스레드에 단다.

### 0. 시작 전 확인할 기준 (사용자가 따로 지정하지 않았다면 먼저 질문)
아래 기준은 지난번에 사용자가 정한 기본값이다. 사용자가 다른 기준을 말하면 그것을 따른다. 정해지지 않은 항목이 있으면 만들기 전에 AskUserQuestion으로 묻는다.
- 매출 기준: 결제금액 합계, 배송비는 매출에서 제외하고 참고 항목으로 별도 표기 (기본값)
- 비교 대상: 전주 대비 (기본값)
- 포함 항목: 핵심 지표, 판매채널별 매출, 카테고리별 매출, 상품 TOP 5 (기본값)
- 형식: 맨 위 요약 3줄 + 항목별 마크다운 표 (기본값)
- 발송 채널: 사용자가 말한 채널

### 1. 데이터 읽기
- Google Drive에서 제목이 '_판매관리'로 끝나는 구글 시트 중 가장 최근에 수정된 파일을 찾는다. (예: 261029_판매관리) 못 찾으면 발송하지 말고 이유를 보고한다.
- 탭 '판매내역', 열: 주문일, 주문번호, 판매채널, 카테고리, 상품명, 옵션, 수량, 판매단가, 결제금액, 배송비. '대시보드' 탭은 쓰지 않는다.
- 시트가 8천 행 이상이고 날짜순이다. 전체를 읽지 말고 끝쪽 행만 범위(예: A7380:J7720)로 나눠 읽는다. 필요한 기간(전주 월요일~지난주 일요일)이 모두 포함됐는지 날짜로 확인한다. 한 번에 반환되는 행이 잘리지 않았는지도 본다.
- 숫자는 쉼표가 있는 문자열이므로 쉼표를 제거해 계산한다. 같은 주문번호가 여러 행일 수 있다.

### 2. 기간
- 실행일(한국시간) 기준 직전 월요일~일요일 = 지난주, 그 앞 주 = 전주.
- 헤더 예: 실행일 2026-11-02(월)이면 `[주간 매출 리포트] 10/26(월)~11/01(일)`.

### 3. 집계 (반드시 코드로 계산하고 검산)
- 총매출 = 결제금액 합계. 배송비 합계는 참고 항목으로 따로 표기.
- 주문 건수 = 주문번호 중복 제거 개수. 판매 수량 = 수량 합. 객단가 = 결제금액 합계 ÷ 주문 건수.
- 판매채널별(유통사A/B/C), 카테고리별(모자/의류/액세서리/가방 등), 상품별 매출. TOP 5는 상품명 기준 결제금액 합계 상위 5개.
- 증감률은 전주 대비, 소수 첫째 자리, +/- 부호 표기. 비중은 해당 주 매출 기준.
- 검산: 채널 합계와 카테고리 합계가 총매출과 일치하는지 확인한다. 비중은 반올림 때문에 합이 100.0%와 다를 수 있다.

### 4. 슬랙 발송 규칙
1. 먼저 slack_read_channel로 채널의 최근 메시지를 읽어, 첫 줄이 `[주간 매출 리포트] M/D(월)~M/D(일)`(지난주 기간)과 같은 메시지가 이미 있으면 보내지 않고 종료한다. (이미 있는 메시지의 스레드를 고치려면 사용자 확인 후 수정본 답글로 단다.)
2. 없으면 채널에는 `[주간 매출 리포트] M/D(월)~M/D(일)` 한 줄만 slack_send_message로 보낸다.
3. 리포트 본문은 방금 보낸 메시지의 message_ts를 thread_ts로 지정해 스레드에 한 번에 보낸다.
4. 슬랙 연결로는 메시지를 지우거나 수정할 수 없다. 잘못 보냈다면 수정본 답글을 달고 이전 답글은 사용자가 직접 삭제해야 한다고 알린다.

### 5. 스레드 본문 형식
```
📊 요약
• 매출 N원, 전주(N원) 대비 ±N.N% (배송비 N원 별도)
• 주문 N건(±%), 판매수량 N개(±%), 객단가 N원(±%)
• 채널/카테고리 주요 증감 한 줄

1. 핵심 지표  | 지표 | 금주 | 전주 | 증감 |  (총매출, 주문 건수, 판매 수량, 객단가, 참고: 배송비 합계)
2. 판매채널별 매출  | 채널 | 금주 매출 | 비중 | 전주 매출 | 증감 |  (합계 행 포함)
3. 카테고리별 매출  | 카테고리 | 금주 매출 | 비중 | 전주 매출 | 증감 |  (합계 행 포함)
4. 상품 TOP 5  | 순위 | 상품명 | 금주 매출 | 판매 수량 | 전주 대비 |

_출처: 구글 시트 '<시트명>' > 판매내역. 주문 건수는 주문번호 기준 중복 제거, 객단가 = 결제금액 합계 ÷ 주문 건수. 채널 비중은 반올림으로 합이 100.0%와 다를 수 있습니다._
```
- 슬랙 마크다운 표는 `|` 구분자를 이스케이프하지 않는다. 셀 안에 `|`가 들어갈 때만 `\|`.

### 6. 마무리
보낸 메시지 링크와 핵심 수치 한 줄을 사용자에게 알린다. 사용자가 원하면 매주 월요일 자동 발송을 예약 작업으로 만든다. 예약 시에는 질문 없이 끝까지 진행하도록 위 기준을 모두 프롬프트에 풀어 쓴다.
